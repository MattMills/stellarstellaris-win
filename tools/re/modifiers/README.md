# Modifier RE helpers

The scripts the modifier study (docs/modifiers.md, docs/modifier_graph.md) used on hippo, against the
GOG 4.5.2 build with PDB names in /root/fnm_tmp (names452.tsv, full452.asm, data452.tsv). Their
inputs and outputs too big for the repo stay in /root/fnm_tmp/modrep: initdefs.txt (the
InitDefinitions disassembly, 66 MB), runs.txt, ss.txt, and modifiers.log, the vanilla 4.5.2 one
that C:\lfm\validate_load.sh compares a load with. enums.txt, hdefs.tsv, sm_idx.txt and
sm_names.txt are small outputs kept here.
